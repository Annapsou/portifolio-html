# Personal Portfolio

This is a simple personal portfolio website built using semantic HTML.

## 📌 About the Project

This project was created as part of my front-end learning journey. It includes a semantic structure with header, main, sections, and footer — featuring an introduction about me, my skills, sample projects, social links, and a contact form.

## 🚀 Technologies Used

- HTML5 (Semantic)

## 📷 Features

- About Me section
- Skills list (Hard Skills & Soft Skills)
- Project showcase with images and descriptions
- Social links (GitHub & LinkedIn)
- Contact form
